# TeacherHelp

TeacherHelp is an AI-powered web platform designed to help independent English teachers create, personalise, and organise teaching materials.

## Features

* AI-powered worksheet generation
* Student profile management
* Personalised teaching materials
* Editable worksheets
* Worksheet library and organisation

## Planned Technology Stack

* Next.js
* React
* Tailwind CSS
* Supabase
* PostgreSQL
* AI API

## Project Status

🚧 Currently in development.

## MVP Goal

The first version of LessonForge will allow English teachers to:

1. Create an account
2. Manage student profiles
3. Generate personalised English worksheets
4. Edit generated materials
5. Save worksheets
6. Access them later through a personal library
